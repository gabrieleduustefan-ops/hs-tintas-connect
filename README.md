# H S Tintas: Trusted Paints

# Prompt para o Lovable — Site da H S Comércio de Tintas



Crie um site moderno, profissional, responsivo e focado em conversão para a empresa **H S Comércio de Tintas**, localizada em Santa Rosa, Rio Grande do Sul.



O objetivo principal do site é transmitir confiança, destacar o bom atendimento da empresa e facilitar pedidos de orçamento pelo WhatsApp.

**Segmento:** Loja de tintas

**Telefone:** (55) 3512-1256

**Instagram:** @hs.tintas

**Facebook:** HsTintas

**Avaliação no Google:** 4,9 estrelas, com cerca de 30 avaliações



A empresa é elogiada pelos clientes principalmente por:



* ótimo atendimento;

* vendedores atenciosos;

* bons preços;

* entrega;

* boa relação custo-benefício.



## Estilo visual



Crie uma identidade visual forte e moderna para uma loja de tintas.



Use um layout clean, profissional e agradável, com bastante espaço em branco e elementos visuais relacionados a cores, pintura, renovação de ambientes e construção.



A paleta pode utilizar cores vibrantes de forma elegante, com uma base neutra e detalhes coloridos que remetam a tintas.



Evite um visual exageradamente colorido ou infantil.



O site deve transmitir:



**confiança + qualidade + variedade + atendimento próximo + preço competitivo.**



Use tipografia moderna e de fácil leitura.

## Funcionalidades importantes



O site deve ser totalmente responsivo para celular, tablet e desktop.



Adicionar um **botão flutuante de WhatsApp** no canto inferior direito.



Todos os botões de orçamento devem abrir uma conversa no WhatsApp com uma mensagem pré-preenchida como:



**"Olá! Encontrei a H S Tintas pelo site e gostaria de solicitar um orçamento."**



Use animações suaves ao rolar a página.



Priorize velocidade de carregamento.



Use boas práticas de SEO.



Criar title e description:



**Title:** H S Tintas | Loja de Tintas em Santa Rosa RS



**Description:** Tintas, acessórios e produtos para pintura em Santa Rosa RS. Atendimento especializado, bons preços e orçamento pelo WhatsApp na H S Comércio de Tintas.



Adicionar dados estruturados de negócio local usando Schema.org LocalBusiness.



O design deve parecer de uma empresa real e consolidada, evitando aparência de template genérico.



O foco principal deve ser fazer o visitante clicar no WhatsApp, ligar para a loja ou visitar o endereço físico.
